# Kyambogo University Computing Students' Association (KYUCSA)

Welcome to the official GitHub organization for the **Kyambogo University Computing Students' Association (KYUCSA)** at **Kyambogo University**.

## What We Do
- Host practical workshops, coding sessions, and collaborative build sprints.
- Help students get started with programming, Git and GitHub workflows, and real-world software projects.
- Support peer mentorship, open-source learning, and shared leadership opportunities.

## Inclusion & Community Standards
We strive to keep KYUCSA welcoming, accessible, and respectful for students at every stage of their journey. Please review our [Code of Conduct](./CODE_OF_CONDUCT.md) before taking part in community events and spaces.
